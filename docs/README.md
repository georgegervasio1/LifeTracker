# Docs

- `PROJECT-INSTRUCTIONS.md`: the instructions pasted into the Claude project (how sessions pick up this repo).
- `brand/`: the LifeTracker logo (SVG, 1024px PNGs) and the variants it was chosen from.
- `screenshots/`: renders from the build history. Finance screenshots use sample data; health uses sample WHOOP data.

Screenshots of the owner's own data (course schedule, training history, grades, pay, taxes, bank data) are kept in
the private kit, not in this public repo. New screenshots committed here must use sample data.
